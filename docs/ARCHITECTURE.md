# 🏗️ بنية المشروع

هذا الملف مرجع لمن يعدّل الكود: أين يوجد كل شيء، والقواعد التي يلتزم بها المشروع.
كل ملف في الكود يبدأ بتعليق يشرح محتواه، والجداول هنا مأخوذة من تلك التعليقات.

## 1. المشاريع في الحل (`Screen Recorder.slnx`)

| المشروع | المحتوى |
|:--|:--|
| `Screen Recorder` | البرنامج نفسه |
| `VirtualCamera` | مصدر الكاميرا الافتراضية (DLL تحمّله خدمة Frame Server في ويندوز) |
| `installer` | التغليف للنشر: النسخة المحمولة (zip) والمثبّت. يعمل في بناء **Release** فقط |

## 2. البرنامج الرئيسي

البرنامج الرئيسي مقسوم إلى ملفات حسب الميزة. كل ملف يبدأ بـ `#include "App.h"`.

- **`App.h`** فيه فقط ما تستخدمه أكثر من ميزة: المكتبات، والأنواع والثوابت المشتركة، والمتغيرات المشتركة (`extern`، ومكتوب فوق كل مجموعة الملف الذي يعرّفها)، والدوال المشتركة مقسومة حسب الملف الذي يعرّفها.
- ما يُستخدم في ملف واحد **يبقى داخل ذلك الملف** ولا يُضاف إلى `App.h`.

| الملف | المحتوى |
|:--|:--|
| `main.cpp` | نقطة البداية: إنشاء النافذة، ومعالجة رسائل ويندوز (الماوس، الكيبورد، المؤقّت...) |
| `App.h` | الأشياء المشتركة بين ملفات البرنامج الرئيسي |
| `AppIds.h` | أرقام عناصر الواجهة الرئيسية |
| `AppState.cpp` | حالة البرنامج المشتركة: المتغيرات اللي بتستعملها أكتر من ميزة |
| `Version.h` | رقم الإصدار (المكان الوحيد) |
| `Commands.cpp` | تنفيذ الكبسات: كل زر بالواجهة الرئيسية بيوصل لهون برقمه (شوف AppIds.h) |
| `UiFrame.cpp` | هيكل الواجهة: الشريط العلوي والجانبي والسفلي، والرسم الكامل لكل إطار |
| `UiSourcesTab.cpp` | تبويب المصادر: قائمة الطبقات وصفوف الصوت وأصوات البرامج |
| `UiStreamTab.cpp` | تبويب البث: الوجهات، ملخّص الإعدادات، عدّاد الرفع، والكاميرا الافتراضية |
| `SettingsPages.cpp` | صفحات نافذة الإعدادات اللي مربوطة مباشرة بإعدادات البرنامج |
| `PreviewEdit.cpp` | المعاينة: رسم المشهد المصغّر، وتحريك وتكبير الطبقات بالماوس مع الالتصاق |
| `SceneLayers.cpp` | طبقات المشهد: إضافة المصادر وحذفها وقوائمها (شاشة، نافذة، كاميرا، صورة، نص، ويب...) |
| `Scenes.cpp` | المشاهد: إضافة، تبديل، تسمية، نسخ، حذف، وحفظ وتحميل من الملف |
| `AppSettings.cpp` | الإعدادات: الإطارات ومعدّل البت والمشفّر، وحفظ وتحميل ملف الإعدادات، والتشغيل مع ويندوز |
| `AudioControl.cpp` | الصوت: تشغيل/إطفاء المصادر، اختيار الجهاز، ومنزلقات العلو |
| `Recording.cpp` | التسجيل: البدء والإيقاف والإيقاف المؤقت، العلامات (فصول يوتيوب)، ومراقبة مساحة القرص |
| `Streaming.cpp` | البث المباشر: الوجهات (يوتيوب، تويتش...)، شعاراتها، مفاتيحها المشفّرة، والبدء والإيقاف |
| `ReplayControl.cpp` | الإعادة: التسجيل المستمر بالذاكرة، الحفظ، وكشف الألعاب |
| `FirstRunSetup.cpp` | الإعداد السريع بأول تشغيل (لقطات / تسجيل / بث) |
| `AppPanels.cpp` | فتح النوافذ الداخلية: الإعدادات، المعرض، المشغّل، القص، فلاتر المايك |
| `AppTray.cpp` | أيقونة جنب الساعة: الإخفاء والإظهار، قائمتها، والخروج |
| `AppIcon.cpp` | أيقونة البرنامج بشريط المهام (منرسمها بالكود، وبتتغيّر وقت التسجيل) |
| `PopupMenu.cpp` | القائمة المنبثقة ونافذة الكتابة الصغيرة (بنفس ستايل البرنامج بدل قوائم ويندوز) |
| `AppUtil.cpp` | أدوات صغيرة مشتركة: رسائل وإشعارات، أسماء ملفات، تحويل إحداثيات، اختيار مجلد |
| `CrashLog.cpp` | سجل الأعطال |
| `Elevation.cpp` | التشغيل كمسؤول (اختياري)، ومهمة التشغيل مع ويندوز في «جدولة المهام» |

## 4. قواعد المشروع

1. **كل ميزة في ملف منفصل**، وكل ملف يبدأ بتعليق يشرح ما فيه.
2. **النوافذ الداخلية** (`Panel`) بدل نوافذ ويندوز المنفصلة، بنفس الثيم، و**بلا قوائم متداخلة**.
3. **نصوص الواجهة بالفصحى**، والتعليقات في الكود بالعربية.
4. **كل زر بأيقونة فقط له تلميح**: بعد `AddHit(r, id)` يُكتب `Tip(id, L"...")` (`Tooltip.h`).
5. **لا رقم يُكتب في مكانين**: رقم الإصدار في `Version.h` فقط، وأرقام العناصر في `AppIds.h`.
6. **البناء بلا تحذيرات** في Debug و Release.

## 5. أرقام العناصر

كل عنصر يُكبس له رقم (`AddHit`). الأرقام لا يجوز أن تتداخل، و**المترجم يتحقق من ذلك عند كل بناء** (`static_assert` في `AppIds.h` و `Panel.h` وملفات النوافذ).

| المجال | لمن | أين |
|:--|:--|:--|
| 1 .. 999 | أزرار وخيارات الواجهة الرئيسية | `AppIds.h` (enum) |
| 1000 .. 49999 | القوائم: مشاهد، وجهات بث، أصوات برامج، طبقات | `AppIds.h` (كتل `IdBlock`) |
| 50000 .. 50099 | إطار النافذة الداخلية (الخلفية، زر الإغلاق) | `Panel.h` |
| 50100 .. 59999 | عناصر النافذة الداخلية المفتوحة (`ID_PANEL_USER` + رقم) | ملف كل نافذة |
| 51000 .. 51099 | محجوزة لقائمة نافذة الإعدادات (`ID_PANEL_SETTINGS_NAV`) | `SettingsPanel.cpp` |
| 60000 فما فوق | عناصر الواجهة الرئيسية داخل نافذة الإعدادات (الرقم الأصلي + `SETTINGS_ID_OFFSET`) | `SettingsPanel.h` |

**إضافة زر جديد:** خذ رقمًا فارغًا تحت 1000 في `AppIds.h`، وأضفه إلى `IdCheck::ALL` في آخر الملف.
**إضافة قائمة جديدة:** أضف `IdBlock` بحجم ثابت، واستخدم `Id(i)` للرسم و `Has(id)` / `Index(id)` في `Commands.cpp`.

## 8. الاختصارات والألعاب التي تعمل كمسؤول

ويندوز يمنع البرامج العادية من رؤية الأزرار المفردة (مثل `F7`) عندما تكون أمامك نافذة بصلاحية أعلى، كلعبة تعمل كمسؤول. لذلك تعمل الاختصارات بثلاث طرق (`Hotkeys.cpp`):

1. `RegisterHotKey`: الطريقة العادية.
2. مراقب الأزرار (Low-level hook): لأزرار الفأرة، وللاختصارات التي يرفضها ويندوز.
3. قراءة حالة الأزرار مباشرة كل 10 ميلي ثانية (`GetAsyncKeyState`): تعمل فقط حين تكون أمامك نافذة بصلاحية أعلى.

إذا وصل الاختصار نفسه من طريقين، يتجاهل `main.cpp` التكرار خلال 300 ميلي ثانية. والحل المضمون لأي لعبة هو خيار **التشغيل كمسؤول** (`Elevation.cpp`).

## 9. سجل الأعطال

إذا توقّف البرنامج فجأة يكتب `CrashLog.cpp` ملفين في مجلد `Crashes`:

- **`crash_….txt`**: الإصدار، ويندوز، نوع الخطأ، ومكانه، ومسار الاستدعاءات.
- **`crash_….dmp`**: صورة ذاكرة البرنامج لحظة الخطأ. تُفتح في Visual Studio: **File ← Open ← File**، ثم **Debug with Native Only**.

لقراءة تقرير من نسخة Release تحتاج ملفات الرموز (`.pdb`) **من نفس البناء**. `package.ps1` يحفظها لكل إصدار في `dist\symbols\v<الإصدار>` (لا تُنشر ولا تُرفع إلى git). **احتفظ بها**.

للتجربة: شغّل البرنامج بـ `--test-crash` فيتوقّف عن قصد بعد فتحه، وفي التشغيل التالي يظهر إشعار بالتقرير.

## 10. إصدار نسخة جديدة

1. غيّر الأرقام في `Screen Recorder\Version.h` (والنص تحتها). إذا لم يتطابقا يفشل البناء.
2. حدّث قسم «الجديد» في `installer\اقرأني.txt` وفي `README.md`، واكتب نص الإصدار في `docs\releases\v<الإصدار>.md` (يُلصق في صفحة الـ Release).
3. ابنِ **Release | x64**. في نهاية البناء يُنتج `installer\package.ps1` في `dist`:
   - `ScreenRecorder-v<الإصدار>-win64.zip` (النسخة المحمولة)
   - `ScreenRecorder-Setup-<الإصدار>.exe` (المثبّت، يحتاج [Inno Setup](https://jrsoftware.org/isdl.php) 6.4.1 أو أحدث)
   - `symbols\v<الإصدار>` (ملفات الرموز، لك فقط)
4. Commit و Push، ثم Release جديد على GitHub بالوسم `v<الإصدار>` وارفع الملفين.
   التحديث التلقائي داخل البرنامج يقرأ وسم آخر Release.
