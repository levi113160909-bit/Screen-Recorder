# مسجّل الشاشة — Screen Recorder

برنامج لتسجيل الشاشة على ويندوز، مكتوب من الصفر بلغة **C++**، بواجهة عربية حديثة.

## المميزات

- 🎬 **مشاهد وطبقات** مثل OBS لكن بواجهة أبسط: أضف شاشات ونوافذ، حرّكها، كبّرها وصغّرها بالفأرة
- 🧲 **التصاق تلقائي** بحواف اللوحة والمصادر الأخرى
- 🖥️ **تصوير عبر بطاقة الرسومات** (Windows Graphics Capture) مع رجوع تلقائي لطريقة GDI عند الحاجة
- 🔊 **صوت النظام والميكروفون** مع اختيار الجهاز ومؤشر مستوى الصوت
- ⚙️ **إعدادات الترميز**: الدقة، معدّل الإطارات، الجودة، معدّل البت، والمشفّر (بطاقة الرسومات أو المعالج)
- 🛟 **MP4 آمن**: لا يضيع التسجيل إذا تعطّل البرنامج
- ⏸️ إيقاف مؤقت، واختصارات **F9** للتسجيل و**F10** للإيقاف المؤقت
- 💾 حفظ المشاهد والإعدادات تلقائيًا

## التقنيات

| الجزء | التقنية |
|---|---|
| الواجهة | Direct2D + DirectWrite |
| التصوير | Windows Graphics Capture + Direct3D 11 |
| الترميز | Media Foundation (H.264 + AAC) |
| الصوت | WASAPI |

## التشغيل

1. افتح `Screen Recorder.slnx` في **Visual Studio 2026** (مع حزمة Desktop development with C++)
2. اضغط **Ctrl+F5**

يتطلب **Windows 10** (إصدار 1903 أو أحدث) أو **Windows 11**.
